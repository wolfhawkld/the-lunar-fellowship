# The Lunar Fellowship 首次启动任务计划

> 状态：Draft / 立即执行版
> 计划窗口：2026-07-25 至 2026-08-23
> 已知条件：八位成员；上海最多四位；其余成员位于北京、南通；午间全在线可能比周二晚混合会议更容易协调。

## 1. 本周的唯一硬目标

完成两件事：

1. 让 Lunar Chat 开始自然运转；
2. 完成第一次 Talk 的时间可行性调查；只有条件合适时，才确认活动。

本周不要求确定长期工具、不启动正式 Lab、不要求成员持续贡献，也不把所有待办都压在发起人身上。

## 2. 首次聚会候选方案

### A. 首选候选：Lunch Edition

- 候选：7 月 28 日或 29 日午间；
- 时长：50 分钟；
- 形式：八位成员各自在公司或附近安静位置上线，可以边吃边聊；
- 成本：零场地费；
- 准备：每人三分钟，无需 PPT；
- 价值：所有成员身份对等，不产生上海主会场和远程旁听者。
- 执行稿：[First Orbit — Lunch Edition](../events/session-00-first-orbit-lunch-edition.md)。

### B. 候选兜底：周二晚全在线

- 候选：7 月 28 日 19:30–20:45；
- 仅在午间整体不可行时采用；
- 仍然优先全在线，不为第一次认识活动承担不必要的场地费用。
- 保留稿：[First Orbit 晚间兜底版](../events/session-00-first-orbit.md)。

### C. 可选：上海本地茶叙

- 四位上海成员可另约共享茶室、茶馆包间或安静咖啡馆；
- 本地茶叙是关系建设，不承担全员正式议程；
- 不在本地茶叙中形成需要北京、南通成员补课的共同决定。

## 3. 角色先占位

| 角色 | 建议人选 | 本周投入 | 必须完成 |
|---|---|---:|---|
| 召集人 | 发起人 | 60–90 分钟 | 建群、定时间、开场、最终确认 |
| 线上桥接人 | 任一成员 | 15–20 分钟 | 建会或协助建会、测试、关注聊天区与掉线 |
| 记录者 | 任一愿意的成员 | 20–30 分钟 | 准备模板、记录主题、会后五条摘要 |
| 参与成员 | 其余成员 | 会前 5 分钟 | 回复投票、填写介绍卡、自愿参加 |

同一人可以兼任，但召集人最好不兼任线上桥接人。

## 4. 逐日任务

### 7 月 25–26 日周末｜内部准备

#### 召集人

- [ ] 创建 `月曜同道会 · Lunar Chat`；
- [ ] 完成 Lunar Hub 首版和时间选择文案；

- [ ] 暂不要求成员在周末回复。

#### 召集人

#### 所有成员

- [ ] 在 Lunar Hub 勾选所有可完整参加的时段；

- [ ] 确认并复制结果，发送到 Lunar Chat。

成员预计投入：2–5 分钟。

完成标准：形成明确的可行性判断。只有存在合适时段、足够成员能够完整参与且语音环境可行时，才确认
First Orbit；否则明确顺延，不把任一候选时间视为承诺。

- [ ] 邀请一位成员完成一次 10 分钟外部加入测试；

- [ ] 确认哪些材料是 Green，哪些只限成员。

完成标准：周一 18:00 前确认会议链接、主持和记录页面。

### 7 月 28 日或 29 日午间

#### 开始前十分钟

- [ ] 线上桥接人确认成员能进入；

- [ ] 给成员 48 小时提出删除、脱敏或修正；
- [ ] 发布三个一分钟反馈问题。

#### 召集人

- [ ] 感谢参与但不要求下一次承诺；
- [ ] 确认下周 Chat 的第一个问题和首位发起者；
- [ ] 不立即推动第二次 Talk。

## 5. 上海本地茶叙：需要时再办

本节只在上海成员希望另行线下见面时使用，不影响全员 Lunch Edition，也不要求在本周完成。

### 场地优先顺序

1. 成员可合法邀请外部访客进入的公司公共区、园区公共区或附近开放空间；
2. 按房间、按小时计费的自助共享茶室；
3. 不设最低消费、能稳定落座的安静咖啡馆；
4. 茶馆小包间；
5. 共享办公会议室，仅在需要正式混合会议设备时采用。

### 预约规则

- 先收集四位上海成员的办公地铁站，再选区域；
- 先定四人可接受的人均上限，再找场地；
- 确认包间费、最低消费、时长、取消政策和是否允许正常交谈；
- 未获得实际参加者确认，不预付不可退款费用；
- 咖啡馆只承载本地社交，不用开放空间讨论敏感事项，也不承担全员远程会议；
- 本地茶叙不形成缺席成员需要补课的组织决定。

### 如果以后确需混合会议

至少准备一台主设备、覆盖房间的会议麦克风/扬声器、稳定网络和一部可开热点的备用手机，并让一位远程成员参加会前收音测试。普通笔记本自带麦克风不应未经测试就作为四人围坐的唯一收音设备。

## 6. 未来四周的轻量任务

### 每周可选动作

- 召集人或成员发布最多一个结构化问题；
- 成员自愿发布 Signal、Ask 或 Echo；
- 有价值的讨论由记录者做一次五条以内摘要；
- 没有内容时不强行发布 Digest。

### Talk 触发

只有同时满足以下条件时再开下一次：

- 一个具体问题；
- 至少三位成员感兴趣；
- 一位愿意召集的人；
- 30–60 分钟可以形成新的理解或下一步。

### Lab 触发

只有至少两位成员主动投入，且两周内能完成一个小产出时再进入 Lab。第一次聚会后不默认启动项目。

### 四周回顾

8 月 23 日前使用三个异步问题完成：

1. 什么让你愿意继续打开 Lunar Chat？
2. 什么让你感到有压力或占用过多时间？
3. 接下来希望保留、停止、尝试什么？

根据反馈形成 operating model v0.2。
