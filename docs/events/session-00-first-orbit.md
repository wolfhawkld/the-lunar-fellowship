# Lunar Session 00 · First Orbit / 初次同航（晚间兜底版）

> 状态：Fallback / 仅在午间方案整体不可行时启用
> 当前首选：[First Orbit — Lunch Edition](./session-00-first-orbit-lunch-edition.md)
> 兜底时间：2026-07-28（周二）19:30–20:45，Asia/Shanghai
> 场地预订时段：建议 19:00–21:00
> 形式：Online-first Hybrid / 线上优先的线下线上混合聚会
> 建议时长：正式环节 75 分钟，预留 90 分钟场地与会议时段

本文保留最初设计的晚间混合会议流程，方便在午间方案无法覆盖大多数成员时快速启用；它不再是第一次聚会的默认方案。当前共八位成员，其中上海线下最多四位，北京、南通成员远程加入。若启用本文方案，仍应先尝试晚间全在线；只有上海成员明确希望同时见面且能低成本获得合适空间时，才组织线下主场。

## 1. 这次聚会只完成四件事

1. 让每位成员知道彼此是谁、正在关注什么；
2. 建立一种可以不表演、可以保留边界的交流安全感；
3. 找出两至三个成员真正愿意继续讨论的共同主题；
4. 确认一个大家感觉舒适的 Chat 节奏，并留下潜在的后续连接。

这次聚会不追求：

- 完整介绍每个人的全部经历；
- 当场解决复杂业务或技术问题；
- 确定所有长期制度；
- 要求每位成员承诺参与项目；
- 录制一份可对外传播的正式内容。

## 2. 完成标准

活动结束时应有：

- 一份仅包含成员主动提供信息的成员兴趣地图；
- 两至三个获得较多关注的主题；
- 一个下周可以在 Chat 继续的具体问题；
- 下一次 Talk 的候选主题；不要求当场确定时间或推动者；
- 一份不包含敏感细节的简短纪要。

## 4. 会前成员介绍卡

建议每人用五分钟填写，允许跳过不想公开的部分：

```text
希望大家怎么称呼我：
我目前最熟悉或最关心的领域：
最近一次让我惊讶的 AI 使用或观察：
我愿意和大家交流/提供的：
我最想从同道会探索的一个问题：
参与方式：线下 / 线上 / 本次无法参加
```

提醒：不填写公司内部项目名、客户名、未公开数据或无权分享的信息。

## 5. 角色分工

| 角色 | 活动中的职责 |
|---|---|
| 召集人 | 说明发起背景、目标和下一步，不包办全部发言 |
| 主持人 | 控制时间、发言顺序、安全感和讨论收敛 |
| 线上桥接人 | 建议由北京或南通成员担任，持续关注线上画面与聊天区，有权提醒现场补充语境 |
| 记录者 | 记录关键词、开放问题和行动，不制作逐字稿 |
| 技术负责人 | 会前测试，现场处理音视频和备用连接 |

人数较少时可以兼任，但召集人不建议同时兼任线上桥接人。

## 6. 八人、75 分钟流程

### 00:00–00:05｜到场与连接确认

- 线上、线下成员都用一个词描述此刻状态；
- 线上桥接人逐位确认线上成员可以听见；
- 屏幕展示四个活动目标。

### 00:05–00:11｜为什么在这里

召集人用不超过六分钟说明：

- 为什么发起 The Lunar Fellowship；
- 它不是公司内部项目，也不是泛兴趣聊天群；
- 首月只是试运行，不要求长期承诺；
- 今晚最重要的是认识彼此，而不是展示自己。

### 00:11–00:16｜安全边界与交流方式

主持人说明：

- 带走启发，不带走未经允许的内容；
- 不讨论无权分享的公司或客户信息；
- 默认不录音、不录像；
- 可以 Pass，可以不开摄像头；
- 单次发言控制在约两分钟，帮助更多人参与。

随后给所有人一分钟安静书写：

> 如果今晚只认识一个有意思的人，或带走一个有价值的问题，我希望是什么？

### 00:16–00:44｜成员自我介绍

每人回答四点：

1. 我是谁，以及我熟悉的领域；
2. 最近一次让我惊讶的 AI 使用或观察；
3. 我愿意交流或提供什么；
4. 我想和大家探索什么。

八位成员每人约三分钟，剩余时间用于环节切换。成员也可以把部分内容写在聊天区。

主持人不逐人点评，只捕捉关键词，避免把介绍环节拖成问答。

### 00:44–00:57｜两至三人小组：从认识到连接

八位成员分成两组，每组尽量同时包含上海线下成员与北京或南通远程成员，避免形成“上海现场组”和“远程旁听组”。

讨论两个问题：

1. 在不涉及敏感信息的前提下，你最近最想探索的一个真实问题是什么？
2. 你希望得到什么帮助，又可以提供什么帮助？

先安静书写一分钟，每人约三分钟，最后共同选出一个值得带回全体的问题。

### 00:57–01:05｜共同主题地图

- 每组用一分钟报告一个问题；
- 记录者将相近问题归为主题；
- 成员用表情或一句话指出最愿意在 Chat 继续的主题；
- 只记下两至三个主题，不当场展开解决。

### 01:05–01:11｜确定下一周的 Chat 起点

只确认：

- 下周在 Chat 继续哪一个具体问题；
- 谁愿意首先发布一条 Signal；没有志愿者时由召集人发起；
- 哪些话题具有后续 Talk 潜力，但暂不约会。

允许“感兴趣但暂不承诺”。首次聚会不要求形成项目或长期任务。

如果现场没有自然形成合适行动，启用默认方案：

> **7-day Lunar Signal**：未来七天，由愿意参与的成员各自在 Lunar Chat 发布一条真实 AI 实践或问题，采用 `[Signal] 做了什么 / [Why] 为什么值得关注 / [Ask] 想讨论什么` 的三行格式；不设置人数指标。周末由召集人用五条以内总结出现的主题。

### 01:11–01:15｜结束

每人用一句话完成：

> 我今晚带走的是……

召集人确认纪要发布时间、下一步和反馈入口。合影仅在所有入镜者明确同意后进行；不希望入镜的成员可以关闭画面或离开取景范围。

## 7. 混合会议的最低要求

第一次活动采用“线上优先”，不是让线上成员旁听线下聚会：

- 议程、介绍卡、记录和投票都放在线上；
- 每轮讨论主动先确认线上成员是否要发言；
- 指定一位线上桥接人，不让主持人同时照顾所有技术细节；
- 线下只保留一个设备开启麦克风和扬声器，避免回声；
- 使用能覆盖房间的收音设备，摄像头尽可能看到所有线下成员；
- 线下成员避免多人同时插话或进行线上听不见的旁聊；
- 如果现场音频连续五分钟无法恢复，正式环节转为全员线上加入；
- 线下聚餐或自由交流属于可选社交环节，不替代正式议程。

## 8. 可直接发送的文案

### 建群欢迎语

```text
欢迎来到「月曜同道会 · Lunar Chat」。

这里连接的是来自不同公司、专业和实践路径，但对 AI 生产力变化有相近判断与行动意愿的个人。我们先从认识彼此、分享真实观察和提出好问题开始，再逐步形成 Talk、Session 和 Lab。

群里不要求高频发言，也不要求成熟结论。一个表情、一个问题、一段实践观察，都可以是有效参与。

共同底线：
1. 带走启发，不带走未经允许的内容；
2. 分享自己的判断，不分享无权分享的信息；
3. 不转发、不截图、不录制成员内内容，除非获得相关成员同意；
```

## 10. 三问反馈

活动后只收集三个问题：

1. 哪个环节最帮助你认识其他成员？
2. 哪个环节让你感到有压力、被忽略或效率不高？
3. 下一次你愿意以哪种方式参与：旁听、提问、分享、主持、记录、发起小实验？

反馈可以私下发送给召集人，不要求在群内公开。
